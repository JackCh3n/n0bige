SQL Server 脚本代替开机自动启动

Posted on 2019-01-26 Edited on 2026-11-09 In 技巧 Word count in article: 338 Reading time ≈ 1 mins.

作用

减少不必要的内存和电池电量，让电池🔋支撑整个课程。

方法

先找到开机自启动的服务，记录并转成脚本的形式来按需要运行，具体如下。

徽标键+R 输入Services.msc运行服务管理器

直接输入Sql快速定位到SQL开头的服务，找到自动启动的服务。（多个）

双击对应的服务，并将服务名称复制到记事本先记录下

停止对应的服务，并把对应的服务启动类型全部设置为“手动”

复制以下文本，并将对应的服务改成你刚记录的服务名称

例如：MSSQLFDLauncher服务则改成 NET START MSSQLFDLauncher

保存为Start SQL Server.bat文件（启动服务）

例如：MSSQLFDLauncher服务则改成 NET STOP MSSQLFDLauncher

保存为Stop SQL Server.bat文件(关闭服务)

bat演示停止SQL Server服务

bat演示启动SQL Server服务

如果出现启动失败问题，请自行手动启动。或Google对应的解决方法。

MS SQL Server 此数据库没有有效所有者

Posted on 2018-11-05 Edited on 2026-11-09 In 技巧 Word count in article: 132 Reading time ≈ 1 mins.

问题

标题: Microsoft SQL Server Management Studio此数据库没有有效所有者，因此无法安装数据库关系图支持对象。若要继续，请首先使用“数据库属性”对话框的“文件”页或 ALTER AUTHORIZATION 语句将数据库所有者设置为有效登录名，然后再添加数据库关系图支持对象。

按钮:

确定

解决方法

use [数据库名]
EXEC sp_changedbowner ‘sa’

意思就是把数据库的权限给sa

黑苹果洗白解决无法使用Siri iMessage FaceTime

Posted on 2018-10-28 Edited on 2026-11-09 In hackintosh Word count in article: 663 Reading time ≈ 2 mins.

本文适用于Clover启动的黑苹果，并在10.13.3上成功启用Siri iMessage FaceTime

原理

MacOS每次开机时ROM（UUID生成，最后12位）和MLB（Board Serial Number）是标准和唯一的OS值。如果该值从开机启动发生变化，那么iMessage会无法激活，苹果将把你的UUID、序列号或苹果ID拉入黑名单，三叶草生成的ROM和MLB值也自动列入黑名单。而黑苹果没有官方授予的这些值，如果不手工设置，则被列入黑名单，无法使用iMessage，FaceTime和Siri。

操作步骤

1.打开clover configurator挂载EFI，打开config.plist

2.保证Rt Variables里里面都是空白的

3.去SMBIOS里面点击下拉选项

4.初步选择机型，组装机推荐选择iMac，根据自己的平台选择具体型号

5点击Generate New随机生成Serial Number，自动生成Board Serial Number （无需修改）

6复制生成的Serial码去苹果官网https://checkcoverage.apple.com查询，如果你能查到相关信息，继续点击shake随机生成，直到查询结果为“很抱歉，此序列号无效。请检查您的信息，然后再试。”为止。

这说明这个序列号没有被白苹果用户占有，你可以使用它作为自己的序列号。

7在System Parameters 中的Custom UUID 新生成一个UUID

8.复制此UUID和粘贴在“Smuuid”字段中的SMBIOS节,保存config.plist

10在终端运行defaults write com.apple.finder AppleShowAllFiles Yes && killall Finder（意思是显示隐藏文件）

继续运行

11.清空垃圾桶。如果说文件仍在使用，立即启动后清空

12.打开磁盘工具，选择你的系统分区，并重建权限。完成后重启（磁盘工具里面的急救就可以了），或者用软件Kext Wizard重建权限也可以

13.重启完成后会重新设置一些内容

14.在终端运行defaults write com.apple.finder AppleShowAllFiles No && killall Finder (意思是不显示隐藏文件，喜欢显示的可以不运行此项)

另外：一些用户指出，你的网络必须设置en0。你可以用关于本机－系统报告，点击任一以太网或WiFi，确保您的 BSD 设备名称为en0。如果不是，重新设置您的网络进/Library/Preferences/SystemConfiguration和删除”NetworkInterfaces.plist”和“”preferences.plist”

正常状态下只要iPhone或者iPad有开通iMessage 和FaceTime 一般都是可以正常使用的

参考http://bufans.cn/?p=163 按实际操作过程进行修改

MS SQL Server 阻止保存要求重新创建表的更改

Posted on 2018-10-22 Edited on 2026-11-09 In 技巧 Word count in article: 172 Reading time ≈ 1 mins.

不允许保存更改。您所做的更改要求删除并重新创建以下表。您对无法重新创建的标进行了更改或者启用了“阻止保存要求重新创建表的更改”选项。

SQL Server 2008

工具 - 选项 - 设计器 - 表设计器和数据库设计器 - 阻止保存要求重新创建表

取消勾选☑️

SQL Server 2012

工具 - 选项 - Designer - 表设计器和数据库设计器 - 阻止保存要求重新创建表

取消勾选☑️

取消勾选后再次操作修改即可保存修改，如果不行则可以尝试重新打开SQL Server

iOS 8 9 10屏蔽系统更新描述文件

Posted on 2018-09-16 Edited on 2026-11-09 In 技巧 Word count in article: 528 Reading time ≈ 2 mins.

食用过程

一、该工具主要功能如下：
1. 屏蔽iOS系统的更新提示
2. 屏蔽系统自动下载最新版固件

二、该工具安装步骤如下
1、首先需要到“设置-> 通用 -> iPhone存储空间”*（iOS 11以下系统为“设置 -> 通用->存储空间与iCloud用量->管理存储空间”）*中查看系统是否已经自动下载了最新版的固件，如果有，请删除后重启手机。如果没有，请直接进行第2步。

2、安装描述文件，在弹窗中点击“允许”；

描述文件下载地址(更多地址参考博客文章): https://f.tiiao.cn/2018/09/15/tvos.mobileconfig

3、接下来会弹出安装描述文件的界面，点击右上角“安装”，输入设备“锁屏密码”后按提示完成操作并重启设备；

4、重启设备后，桌面会出现“Feedback”图标表示成功*（此图标无法删除，可以将其移入文件夹中隐藏）*，此时系统将不会检测到iOS系统更新，也不会自动下载固件；

提示1：安装成功后，在“设置 -> 通用 -> 软件更新”菜单如果还有提示更新的图标，点进去之后依然提示是最新版，这是正常的，无需处理。

提示2：如果需要重新打开检查更新的功能，需要进入“设置 -> 通用 -> 描述文件与设备管理 -> tvOS 11 Beta Software Profile”，点击“删除描述文件”然后再点击“删除”，重启手机后即可。

升级ios12

如果安装了屏蔽更新需要先卸载屏蔽更新描述文件，然后再安装更新的描述文件，没有安装屏蔽更新则直接安装根据提示操作然后重启，重启设备后，在设备上依次打开“设置->通用->软件更新”，检测到iOS 12更新后点击下方“下载并安装”按钮，保持网络连接等待安装包下载完成后自动更新。

更新描述文件：https://f.tiiao.cn/2018/09/15/iOS12.mobileconfig
