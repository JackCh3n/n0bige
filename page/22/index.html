TortoiseGitPlink Fatal Error

Posted on 2019-02-04 Edited on 2026-11-09 In 技巧 Word count in article: 103 Reading time ≈ 1 mins.

问题

pull时，弹窗出现以下内容

TortoiseGitPlink Fatal Error

Disconnected: No supported authentication methods

available (server sent: publickey)

确定

可能的原因

Git和TortoiseGit有冲突

解决方法

TortoiseGit—Settings–Network–修改SSH client为 git的ssh.exe

例如我的具体地址是：

C:\Program Files\Git\usr\bin\ssh.exe

替换后，再次尝试pull，博主改过则是可以正常pull

tortoisegit 常见错误disconnected no supported authentication methods available(server sent: publickey)

360F4刷机经历教程

Posted on 2019-02-02 Edited on 2026-11-09 In 技巧 Word count in article: 1.1k Reading time ≈ 4 mins.

由来

​ 网络上一大堆刷机教程，我也是按着他们的方法来进行刷机的，但是找了几个教程都是老的，哟哟几个关键性的问题都没有解决，使刷机过程不能正常的进行，而我写这个则是为了填那些之前人挖的坑。（线刷，其他未试）

刷机

​ 三步走，装驱动，下固件，刷机

驱动和固件官方和论坛都有提供，为此我也在网盘上做了备份。

刷机教程可以按着软件来走，所提供的软甲和驱动都安装完成且可以正常打开。

我这边引用了360论坛@Smile草莓所写的线刷部分正确教程，作为备份。

错误的过程

​ 我一直错误第6步，不管是如何的重启还是换电脑，换端口换数据线都是不行，后面再论坛上有要按音量键和开机键 再插入也是没有效果，更有有人说是驱动没有装，要插入电脑的几秒内在设备管理器里面将带有感叹号的驱动给装上，奈何手速不如人家，多个USB口都没有实现。不过这位小老弟的思路是对的，确实是驱动没有完全的安装完。

​ 我后面再在找到了360F4完美强刷教程，说是不用退出云账号等云云都是可以的，抱着死马当活马医的心态我还是试了一下。结果还是可以的。在第六步校验完后用MTK软件进行强刷。

微信公众订阅号批量取消脚本软件

Posted on 2019-01-29 Edited on 2026-11-09 In 技巧 Word count in article: 849 Reading time ≈ 3 mins.

由来

​ 可能是真的太闲了，在整理微信小号的时候发现之前几个在挂机赚钱的几个号，不管是微信订阅号还是公众号都关注了一大堆有的没的，消息不停，看着都难受，便是突发其想将其订阅号批量取关，搜索了下没有类似的软件，也害怕（期中一个号还因为登录环境问题今天刚辅助验证了）于是便动手录个脚本，可以运行但其效率不高，又看着是vb语言便生写脚本的冲动。

​ 时间太久了Vb的语法基本都忘光了，用的是按键精灵（老版破解），语法提示不是很清楚（真的忘得差不多了），且其语法应该是修改过的，与Vb大有不同。

​ 这个脚本软件做的过程还是挺有趣的，一开始是纯录制接着是指定x,y坐标，最后才是句柄的相对坐标和位置，还通过颜色来实现（图片错误率高），一点点升级

使用

软件分自动挡和手动挡，推荐手动挡

  1. 自动挡则是登录微信pc版，开启软件，选中对应的公众号类别就可以了

  2. 手动挡则是登录微信pc版，手动点开对应的公众号类别，开启软件，再选中对应的公众号类别就可以了

手动挡使用

手动点开公众号或是订阅号

停止

双击exit.bat 批处理结束

BUG

  1. 自动挡，即自动寻找公众号和订阅号可能出现找不准确的情况，颜色干扰
  2. 不能停止？？？不知道怎么写热键停止，尝试了下无果便用批处理来直接结束进程
